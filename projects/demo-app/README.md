# ডেমো টাস্ক লিস্ট

এটি Universal Project Audit Workflow যাচাই করার জন্য তৈরি একটি ছোট বাংলা ওয়েব অ্যাপ।

## চালানোর নিয়ম
1. `projects/demo-app/index.html` ফাইলটি ব্রাউজারে খুলুন।
2. নতুন কাজ লিখে **যোগ করো** চাপুন।
3. চেকবক্সে টিক দিয়ে কাজ সম্পন্ন করুন।
4. **সম্পন্ন কাজ মুছো** দিয়ে সম্পন্ন কাজ সরান।

## সীমাবদ্ধতা
- এটি শুধু HTML, CSS ও JavaScript ব্যবহার করে।
- কোনো সার্ভার, লগইন বা ডেটাবেস নেই।
- কাজগুলো পেজ রিলোড করলে মুছে যাবে।
- এই ডেমো নিজে থেকে Production-এ Deploy করা হয় না।

## Workflow পরীক্ষা
GitHub Actions-এর Universal Project Audit and Repair রান থেকে static-check ফলাফল, AI audit ফলাফল ও report artifact দেখুন। AI audit-এর জন্য অন্তত একটি সমর্থিত provider API key GitHub Actions secrets-এ থাকতে হবে।
