Firebase কানেক্ট করুন

আপনার Firebase প্রজেক্টের কনফিগ নিচে পেস্ট করুন, অথবা config/firebase-config.js ফাইলে সেট করে দিন। কনফিগ শুধু আপনার ব্রাউজারেই সেভ থাকবে।

কনফিগ কোথায় পাব?
  1. console.firebase.google.com → আপনার প্রজেক্ট খুলুন
  2. ⚙️ Project settings → Your apps → Web app ( </> ) সিলেক্ট করুন
  3. SDK setup and configuration → Config রেডিও বাটন → কোড ব্লকটি কপি করুন
  4. এর আগে Authentication → Sign-in method → Google চালু করুন, Firestore ও Storage তৈরি করুন
  5. এই সাইটের ডোমেইনটি Authentication → Settings → Authorized domains-এ যোগ করুন

ডেমো মোডে সব ডেটা শুধু আপনার ব্রাউজারে সেভ থাকবে (Firestore-এ নয়)। পরে Settings থেকে যেকোনো সময় Firebase কানেক্ট করতে পারবেন।
